Realm was one of those libraries that showed me just how cool open source can be.

Saving data to disk in an iOS app is always tricky. There are easy options for small bits of data, but once you're dealing with complex, queryable graphs of data, the options all come with a steep learning curve.

Realm's goal was to give us both: an incredibly powerful persistence engine behind an incredibly simple API. Using it for the first time felt like magic.

After a few weeks of using it, I posted a tech talk about it on my YouTube channel. Thanks to the power of the internet, the Realm team saw it and invited me to join them.

At Realm I wore a few hats, contributing to the core product as well as building and maintaining a collection of tools and component libraries around it.
