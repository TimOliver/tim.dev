Realm is an embedded database framework for iOS and Android apps. Its database files use a custom format, so a proper browser app was needed to open them up and look inside.

Realm Browser is a simple Mac app that uses the same Realm SDK as iOS apps, so it can open, view and edit any Realm file.

I was in charge of Realm Browser during my time at Realm, adding features like opening encrypted files, and releasing it on the Mac App Store.

Realm Browser was eventually retired in favour of a new app, Realm Studio, but I still maintain a fork of it for my own use.
