A new app icon for YT Music, Stephen Radford's open-source YouTube Music app for Mac, which I helped release new versions of. It's still the app's icon today!

I drew it in the macOS Big Sur style so it would sit nicely in the Dock alongside Apple's own apps. The fun part was decoding what Google had done with the Chrome icon and applying the same ideas here: a subtle specular highlight to hint at how round the edge is, plus some of Big Sur's reflected light and subsurface scattering.
